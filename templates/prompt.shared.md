# Looper project model

Looper works from one authoritative source path and one approved `stories.json` queue. The active story already contains its complete repository-grounded execution plan. Looper owns source freshness, story locking, harness validation, review budgets, commits, and pass state.

Stay within the active phase. Do not modify `.looper`, change the approved plan, invoke another agent, switch branches, commit, push, or begin another story.
